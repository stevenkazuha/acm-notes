# 强连通分量 Tarjan

## 概念

- **强连通图**：任意两点互相可达
- **强连通分量 SCC**：极大的强连通子图

## Tarjan 算法

```cpp
vector<int> G[N];
int dfn[N], low[N], idx;
int stk[N], top;
bool in_stk[N];
int scc_cnt, scc_id[N];

void tarjan(int u)
{
    dfn[u] = low[u] = ++idx;
    stk[top++] = u;
    in_stk[u] = 1;
    for(int v : G[u])
    {
        if(!dfn[v])
        {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        }
        else if(in_stk[v])
        {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if(dfn[u] == low[u])
    {
        scc_cnt++;
        while(top)
        {
            int x = stk[--top];
            in_stk[x] = 0;
            scc_id[x] = scc_cnt;
            if(x == u) break;
        }
    }
}

void tarjan_all(int n)
{
    memset(dfn, 0, sizeof(dfn));
    memset(in_stk, 0, sizeof(in_stk));
    idx = top = scc_cnt = 0;
    for(int i = 1; i <= n; i++)
        if(!dfn[i]) tarjan(i);
}
```

## 真题演练

### 【2024 ICPC 杭州 F - Fuzzy Ranking】

**原题**：[Codeforces Gym 105657 F](https://codeforces.com/gym/105657/problem/F)

**简述**：有 k 个排列，排列里每个数 i 和 j 如果 i 排在 j 前面就意味着 i "优越于" j（优越关系有传递性）。如果 x 能到 y 且 y 能到 x，则 x 和 y 构成模糊对。多次查询区间 [l, r] 内有多少模糊对。

**思路**：优越关系 → 建图（i→j 表示 i 优于 j）。模糊对 = 在同一个强连通分量内。Tarjan 求 SCC 后，每个 SCC 大小 c 贡献 c(c-1)/2 对。然后用分块或莫队维护区间内的贡献之和。

**复杂度**：O(nk + q√n)

```cpp

const int N = 100005;

vector<int> g[N];
int dfn[N], low[N], stk[N], top, tmp;
bool in_stk[N];
int scc_cnt, scc_id[N];

void tarjan(int u)
{
    dfn[u] = low[u] = ++tmp;
    stk[top++] = u;
    in_stk[u] = 1;
    for(int v : g[u])
    {
        if(!dfn[v])
        {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        }
        else if(in_stk[v])
            low[u] = min(low[u], dfn[v]);
    }
    if(dfn[u] == low[u])
    {
        scc_cnt++;
        while(top)
        {
            int x = stk[--top];
            in_stk[x] = 0;
            scc_id[x] = scc_cnt;
            if(x == u) break;
        }
    }
}

    map<pair<int, int>, int> mp;
    for(int i = 1; i <= k; i++)

        for(int j = 1; j <= n; j++)

            if(j > 1)
            {

                if(!mp.count({u, v}))
                {
                    mp[{u, v}] = 1;
                    g[u].push_back(v);
                }
            }
        }
    }

    // Tarjan 求所有强连通分量
    for(int i = 1; i <= n; i++)
        if(!dfn[i]) tarjan(i);

    return 0;
}
```

**对应知识点**：Tarjan + 缩点。强连通分量里任意两点互相可达 → 两两配对。缩点后的 DAG 性质——强连通分量之间不会互相反向连边，所以可以放心用拓扑序 DP 或分块处理。
