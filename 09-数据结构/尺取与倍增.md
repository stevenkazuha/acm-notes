# 尺取法与倍增

## 尺取法（双指针）

适用于"满足某条件的最小区间"类问题。两个指针同向移动。

```cpp
// 求和 >= target 的最短连续子数组
// 前提：a[i] >= 0 且 target > 0；含负数时需改用前缀和 + 单调队列
int min_len(int a[], int n, int target)
{
    int l = 0, r = 0, sum = 0, ans = n + 1;
    while(r < n)
    {
        sum += a[r];
        r++;
        while(sum >= target)
        {
            ans = min(ans, r - l);
            sum -= a[l];
            l++;
        }
    }
    return ans == n + 1 ? 0 : ans;
}
```

## 三指针（找最长无重复子串）

```cpp
int longest_unique(string s)
{
    int l = 0, r = 0, ans = 0;
    unordered_set<char> st;
    while(r < s.size())
    {
        while(st.count(s[r]))
        {
            st.erase(s[l]);
            l++;
        }
        st.insert(s[r]);
        r++;
        ans = max(ans, r - l);
    }
    return ans;
}
```

## ST 表（区间最值，O(1) 查询）

倍增思想在静态区间查询上的应用。`st[i][j]` 表示从 i 开始、长度 2^j 的区间最值。

```cpp
const int N = 100005;
int st[N][20], lg[N];

void build(int a[], int n)
{
    lg[1] = 0;
    for(int i = 2; i <= n; i++) lg[i] = lg[i/2] + 1;
    for(int i = 1; i <= n; i++) st[i][0] = a[i];
    for(int j = 1; (1 << j) <= n; j++)
        for(int i = 1; i + (1 << j) - 1 <= n; i++)
            st[i][j] = max(st[i][j-1], st[i + (1 << (j-1))][j-1]);
}

int query(int l, int r)
{
    int k = lg[r - l + 1];
    return max(st[l][k], st[r - (1 << k) + 1][k]);
}
```

**要点**：

- 只能处理静态区间，元素修改后必须重建
- 两个长度为 2^k 的区间覆盖 [l, r]，重叠不影响最值
- 求最小值把 `max` 换成 `min`；区间 gcd 也可以这样做
- 空间 O(n log n)，n = 1e5 时约 8 MB

## 倍增

倍增就是每次跳 2^j 步，常见用法：

- 快速 LCA：往上跳 2^j 层，见 [[06-图论/树链剖分与LCA]]
- ST 表：区间长度按 2 的幂拆分
- 快速幂：指数按二进制拆分，见 [[02-算法基础/分治与二分]]
