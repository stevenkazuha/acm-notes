# 位运算

## 常用操作

```cpp
// 判断第 i 位是否为 1
if(x & (1 << i))

// 将第 i 位设为 1
x |= (1 << i)

// 将第 i 位设为 0
x &= ~(1 << i)

// 翻转第 i 位
x ^= (1 << i)

// 取最低位的 1
int lowbit = x & (-x)

// 统计 1 的个数
__builtin_popcount(x);       // int
__builtin_popcountll(x);    // ll

// 取反
~x

// 左移 / 右移
x << 1;    // 相当于 *2
x >> 1;    // 相当于 /2
```

## 常见应用

### 1. 枚举子集（状态压缩）

```cpp
// 枚举 mask 的所有子集（含空集）
for(int sub = mask; ; sub = (sub-1) & mask)
{
    // 处理 sub
    if(sub == 0) break;
}
```

### 2. 汉明距离

```cpp
int hamming(int a, int b)
{
    return __builtin_popcount(a ^ b);
}
```
