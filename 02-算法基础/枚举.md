## 枚举子集

### 二进制枚举

```cpp
int n = 3;
for(int mask = 0; mask < (1<<n); mask++)
{
    // mask 的每一位代表第 i 个元素选/不选
    for(int i = 0; i < n; i++)
    {
        if(mask & (1<<i)) cout << i << ' ';
    }
    cout << endl;
}
```

### 枚举非空子集

```cpp
for(int sub = (1<<n) - 1; sub > 0; sub = (sub-1) & ((1<<n)-1))
{
    // 处理 sub
}
```

## 枚举约数

```cpp
vector<int> get_divisors(int x)
{
    vector<int> res;
    for(int i = 1; i <= x/i; i++)
    {
        if(x % i == 0)
        {
            res.push_back(i);
            if(i != x/i) res.push_back(x/i);
        }
    }
    return res;
}
```
