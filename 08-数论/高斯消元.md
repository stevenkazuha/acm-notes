# 高斯消元

## 核心用途

解线性方程组：

```
a11*x1 + a12*x2 + ... + a1n*xn = b1
a21*x1 + a22*x2 + ... + a2n*xn = b2
...
an1*x1 + an2*x2 + ... + ann*xn = bn
```

## 复杂度

O(n³)，n 一般 ≤ 200。

## 浮点数版（实数解）

```cpp
const double eps = 1e-8;
double a[N][N];   // 增广矩阵，最后一列是 b

int gauss(int n)
{
    int r = 0;   // 当前处理到的行
    for(int c = 0; c < n; c++)   // 枚举每一列
    {
        // 找这一列绝对值最大的行（避免精度问题）
        int t = r;
        for(int i = r; i < n; i++)
            if(fabs(a[i][c]) > fabs(a[t][c])) t = i;
        if(fabs(a[t][c]) < eps) continue;   // 这一列全 0，跳过
        // 交换到当前行
        for(int i = c; i <= n; i++) swap(a[t][i], a[r][i]);
        // 消元
        for(int i = 0; i < n; i++)
        {
            if(i != r && fabs(a[i][c]) > eps)
            {
                double div = a[i][c] / a[r][c];
                for(int j = c; j <= n; j++) a[i][j] -= div * a[r][j];
            }
        }
        r++;
    }
    // 判断无解/无穷解
    if(r < n)
    {
        for(int i = r; i < n; i++)
            if(fabs(a[i][n]) > eps) return -1;   // 无解
        return 0;   // 无穷多解
    }
    // 唯一解：a[i][n] / a[i][i]
    for(int i = 0; i < n; i++)
        a[i][n] /= a[i][i];
    return 1;
}
```

## 模质数版（整数解，mod 是质数）

```cpp
ll a[N][N];   // 增广矩阵，所有元素 mod p
ll mod;

ll qpow(ll a, ll b) { /* 快速幂 */ }
ll inv(ll x) { return qpow(x, mod - 2); }

int gauss(int n)
{
    int r = 0;
    for(int c = 0; c < n; c++)
    {
        int t = r;
        for(int i = r; i < n; i++)
            if(a[i][c]) { t = i; break; }
        if(!a[t][c]) continue;
        for(int i = c; i <= n; i++) swap(a[t][i], a[r][i]);
        ll div = inv(a[r][c]);
        for(int i = 0; i < n; i++)
        {
            if(i != r && a[i][c])
            {
                ll factor = a[i][c] * div % mod;
                for(int j = c; j <= n; j++)
                    a[i][j] = (a[i][j] - a[r][j] * factor % mod + mod) % mod;
            }
        }
        r++;
    }
    if(r < n)
    {
        for(int i = r; i < n; i++)
            if(a[i][n]) return -1;
        return 0;
    }
    for(int i = 0; i < n; i++)
        a[i][n] = a[i][n] * inv(a[i][i]) % mod;
    return 1;
}
```

## 经典场景

| 场景 | 说明 |
|------|------|
| 电路中的电流/电压 | 基尔霍夫定律直接列方程组 |
| 概率 DP 的环 | 列方程解出各状态概率 |
| 异或方程组 | 把 XOR 看成 GF(2) 上的加法，高斯消元解 |
| 二次剩余（模素数开方） | 不是高斯消元，但相关 |

## 异或方程组（mod 2 高斯消元）

```cpp
int a[N][N];   // 0/1 矩阵

int gauss_xor(int n)
{
    int r = 0;
    for(int c = 0; c < n; c++)
    {
        int t = -1;
        for(int i = r; i < n; i++)
            if(a[i][c]) { t = i; break; }
        if(t == -1) continue;
        swap(a[t], a[r]);
        for(int i = 0; i < n; i++)
        {
            if(i != r && a[i][c])
                for(int j = c; j <= n; j++)
                    a[i][j] ^= a[r][j];
        }
        r++;
    }
    if(r < n)
    {
        for(int i = r; i < n; i++)
            if(a[i][n]) return -1;
        return 0;
    }
    return 1;
}
```

## 易错点

1. **精度问题**：浮点数版一定要选列主元（绝对值最大的），否则小主元会放大误差
2. **无解 vs 无穷解**：看 `r < n` 的行是否 `a[i][n] != 0`
3. **模运算**：模版消元时要 `(x + mod) % mod` 保持正数
