# 基础树论

## 树的基本性质

- n 个点的图是树 ⟺ n-1 条边且连通
- 树中任意两点路径唯一
- 叶子节点：度数为 1 的节点

## 树的存储

```cpp
vector<int> tree[N];

void add(int u, int v)
{
    tree[u].push_back(v);
    tree[v].push_back(u);
}
```

## 树的遍历

```cpp
int fa[N], depth[N];

void dfs(int u, int f)
{
    fa[u] = f;
    depth[u] = depth[f] + 1;
    for(int v : tree[u])
    {
        if(v != f) dfs(v, u);
    }
}
```

## 树的直径

```cpp
int diam = 0;

int dfs(int u, int f)
{
    int d1 = 0, d2 = 0;
    for(int v : tree[u])
    {
        if(v == f) continue;
        int d = dfs(v, u) + 1;
        if(d > d1) { d2 = d1; d1 = d; }
        else if(d > d2) d2 = d;
    }
    diam = max(diam, d1 + d2);
    return d1;
}

int get_diameter()
{
    diam = 0;       // 每棵树重新统计
    dfs(1, 0);
    return diam;
}
```

## 树的重心

```cpp
int root, min_bal = 0x3f3f3f3f;
int sz[N];

void dfs(int u, int f)
{
    sz[u] = 1;
    int mx = 0;
    for(int v : tree[u])
    {
        if(v == f) continue;
        dfs(v, u);
        sz[u] += sz[v];
        mx = max(mx, sz[v]);
    }
    mx = max(mx, n - sz[u]);
    if(mx < min_bal) { min_bal = mx; root = u; }
}

int get_centroid()
{
    root = 0;
    min_bal = 0x3f3f3f3f;   // 每棵树重新统计
    dfs(1, 0);
    return root;
}
```
